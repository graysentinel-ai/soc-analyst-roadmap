# SOC Analyst Learning Roadmap

This roadmap is a learning sequence, not a promise of employment or a fixed-duration qualification. Progress depends on prior knowledge, practice time and evidence quality.

## Stage 0: Learning setup and ethics
- Set up a dedicated learning environment.
- Understand lab isolation, permission and data handling.
- Learn Git and basic documentation.
- Evidence: a short lab-safety checklist.

## Stage 1: Networking foundations
- TCP/IP, OSI model and common protocols.
- IP addressing, subnet basics, DNS, DHCP, HTTP/HTTPS.
- Ports, sockets, routing and network segmentation.
- Evidence: explain a sample connection and document a packet-capture observation.

## Stage 2: Operating system foundations
- Linux filesystem, users, permissions, processes and services.
- Windows users, processes, services and Event Viewer.
- Command-line fundamentals and time synchronisation.
- Evidence: annotated notes showing where relevant system events can be found.

## Stage 3: Security fundamentals
- CIA triad, authentication, authorisation and least privilege.
- Malware, phishing, brute-force attempts and common attack patterns.
- Indicators of compromise and basic threat modelling.
- Evidence: classify fictional security events and explain the reasoning.

## Stage 4: Logs and event analysis
- Log sources and event fields.
- Timestamps, host identity, users, source/destination IPs and event IDs.
- Normalisation, parsing and common investigation pitfalls.
- Evidence: analyse a supplied or self-generated benign sample dataset.

## Stage 5: SOC operations and alert triage
- SOC roles and escalation concepts.
- Alert severity, context, false positives and prioritisation.
- Investigation notes and handover quality.
- Evidence: complete a triage worksheet for fictional alerts.

## Stage 6: SIEM concepts and practical work
- Data ingestion, searches, dashboards and alerting concepts.
- Explore a SIEM in a local or authorised training environment.
- Understand detection content and data quality.
- Evidence: documented search queries and screenshots with secrets removed.

## Stage 7: Incident investigation
- Build a timeline from supplied events.
- Correlate endpoint, authentication and network observations.
- Record hypotheses, supporting evidence and limitations.
- Evidence: a concise incident investigation report.

## Stage 8: Detection engineering fundamentals
- Detection logic, conditions, data dependencies and tuning.
- Introductory Sigma rule structure and validation concepts.
- Test detections against known benign or lab-generated events.
- Evidence: one documented detection with test cases and known limitations.

## Stage 9: Portfolio projects
- Authentication-event investigation.
- Suspicious-process triage using a safe sample dataset.
- Detection rule with test cases.
- Incident timeline and final report.

## Completion standard
A learner should be able to explain the work, reproduce the lab, identify limitations and defend their conclusions. Completing a checklist alone does not establish professional competence.
