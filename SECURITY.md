# Security Policy

This repository contains educational documentation and lab exercises. It is not an invitation to test real systems.

- Use only local labs, intentionally vulnerable training environments, or systems with explicit written authorisation.
- Do not commit secrets, credentials, personal data, customer data or private logs.
- Do not include live malware or weaponised payloads.
- Use synthetic or sanitised datasets.

Do not open a public issue containing sensitive vulnerability details or secrets. Use a private reporting channel only if the repository owner has configured one in GitHub. Otherwise, do not submit sensitive data through this repository.
