YOUR LEARNING PATH

From foundations to investigation

Move at your own pace. Complete each stage by explaining and documenting what you learned.

01

Networking foundations

TCP/IP, DNS, DHCP, HTTP/S, ports and packet basics.

02

Operating systems

Linux, Windows, processes, services, permissions and events.

03

Security fundamentals

Identity, common threats, IOCs and security principles.

04

Logs and event analysis

Event fields, timestamps, sources and investigation context.

05

SOC operations

Alert triage, severity, prioritisation and escalation.

06

SIEM concepts

Data ingestion, searches, dashboards and alerting.

07

Incident investigation

Timeline building, evidence correlation and reporting.

08

Detection engineering

Detection logic, Sigma concepts, test cases and tuning.

09

Portfolio projects

Turn practical work into clear, reproducible evidence.

PRACTISE SAFELY

Learning should produce evidence.

Use isolated labs, synthetic datasets and systems you own or are explicitly authorised to test. Record your method, observations, conclusions and limitations.

BUILD YOUR PORTFOLIO

Four project starting points

Authentication event investigation

Analyse fictional authentication events and write a concise investigation report.

PROJECT 02

Suspicious process triage

PROJECT 03

Detection rule with test cases

Create a documented detection for a lab scenario and test expected matches and misses.

PROJECT 04

Incident timeline

Correlate supplied events into a timeline and communicate findings clearly.
