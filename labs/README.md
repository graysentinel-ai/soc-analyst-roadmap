# GraySentinel Practical SOC Labs

Welcome to the GraySentinel SOC Analyst Practical Labs.

These labs provide structured exercises to help learners understand security operations, investigate suspicious activity and develop practical Blue Team skills.

## Available Labs

### Lab 01: Network Traffic Analysis

**Path:** `01-network-traffic-analysis/`

Learn to examine network traffic, understand protocols, analyse DNS and TCP activity, and identify unusual network patterns.

### Lab 02: Operating System Investigation

**Path:** `02-operating-system-investigation/`

Learn to investigate Linux system information, processes, services, authentication activity and system logs.

### Lab 03: Security Event Analysis

**Path:** `03-security-event-analysis/`

Learn to interpret security events, investigate authentication activity, identify suspicious patterns and build event timelines.

### Lab 04: Network Security Investigation

**Path:** `04-network-security-investigation/`

Learn to analyse firewall records, identify allowed and blocked connections, and investigate unusual network activity.

### Lab 05: Endpoint Investigation

**Path:** `05-endpoint-investigation/`

Learn to examine endpoint events, analyse process execution, understand parent-child relationships and identify suspicious behaviour.

### Lab 06: Identity and Access Investigation

**Path:** `06-identity-access-investigation/`

Learn to investigate authentication events, failed logins, privileged access and unusual account activity.

### Lab 07: SIEM Alert Triage

**Path:** `07-siem-alert-triage/`

Learn to analyse SIEM alerts, understand severity, correlate related events and prioritize investigations.

### Lab 08: Detection Engineering

**Path:** `08-detection-engineering/`

Learn the fundamentals of detection engineering, understand Sigma rules and identify potential false positives.

## How to Use These Labs

Follow these steps:

1. Read the lab overview and learning objectives.
2. Understand the prerequisites.
3. Open the supplied dataset or practical resource.
4. Complete the investigation tasks.
5. Answer the investigation questions.
6. Document your observations and findings.
7. Prepare the expected deliverables.

## Lab Safety

- Use only authorized systems and environments.
- Use synthetic datasets where provided.
- Never expose credentials or private information.
- Do not execute suspicious commands from investigation records.
- Follow responsible cybersecurity practices.

## Learning Philosophy

Every lab encourages learners to understand, investigate and document their work.

**Mission → Execute → Evidence → Artifact → Review → Portfolio**
